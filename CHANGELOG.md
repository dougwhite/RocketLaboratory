# Changelog

## 0.1.0

- Independent browser editor/observation viewer with synthetic/native source labels.
- Versioned experiment schema, strict compiler, CLI and serial repeatability campaigns.
- Stdio MCP tools over the shared execution service.
- Optional native offline attachment through an expiring nonce/ack bridge; cross-process ownership and bounded capture/stop behavior.
- Original C++ recorder/controller, strict NNI2 decoder, coordinate conversion and input-delivery qualification diagnostics extracted with MIT attribution.
- Pinned external SDK/RLBot source fetching, safe extraction, local MSVC plugin build script.
- Clear installation, platform, qualification, privacy and distribution boundaries.

Native timing/full-state restore, arbitrary initial state, authored camera interventions, RLBot runtime integration and prebuilt plugin distribution remain outside the qualified v0.1 feature set.
